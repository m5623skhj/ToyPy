# ToyPy — 한글로 쓰는 프로그래밍 언어

ToyPy는 **한글 문장**을 **Python 코드**로 바꿔주는 트랜스파일러입니다.
영어 키워드 대신 자연스러운 한국어 표현으로 코드를 쓸 수 있어요.

```
화면에 보여줘 "안녕하세요!"
```

위 한 줄이 아래 파이썬으로 변환됩니다:

```python
print("안녕하세요!")
```

---

## 빠른 시작

### 1. 준비물
- Python 3.8 이상
- Windows (일부 기능: 키 입력, 콘솔 색상)

### 2. 첫 프로그램 실행
1. `Code/` 폴더에 `hello.dsl` 파일을 만들고 아래 내용을 저장합니다:

   ```
   이름 은 "세상"
   화면에 보여줘 "안녕, " + 이름 + "!"
   ```

2. 트랜스파일:
   ```
   python Toypy.py hello
   ```
   또는 `TranslatorRunner.bat` 더블클릭 (전체 변환)

3. 결과 실행:
   ```
   python PythonScript/hello.py
   ```

### 3. 명령어 한눈에
| 명령 | 동작 |
|---|---|
| `python Toypy.py` | `Code/` 안의 모든 `.dsl` 변환 |
| `python Toypy.py 이름` | 특정 파일만 변환 (확장자 생략 가능) |
| `TranslatorRunner.bat` | 전체 변환 (더블클릭) |

## 프로젝트 구조

```
ToyPy/
├─ Toypy.py          메인 실행기 (auto-import, 경고 검출)
├─ parser.py         DSL → AST 파서 (문장 단위)
├─ expr_parser.py    표현식 전용 AST 파서 (Pratt 스타일)
├─ codegen.py        AST → Python 코드 생성기
├─ ast_nodes.py      AST 노드 정의
├─ KeyWords.py       키워드 목록
├─ Code/             여기에 .dsl 파일을 작성
└─ PythonScript/     여기로 .py 파일이 나옵니다
```

**동작 흐름**:
```
.dsl  →  parser.py (문장 AST)  →  expr_parser.py (표현식 AST)  →  codegen.py  →  .py
```

두 단계 파서 구조라 **중첩·복합 표현식**에서도 결합 순서가 정확합니다.
예를 들어 `a + b 를 숫자로 봐줘`는 `a + int(b)`로 올바르게 결합됩니다.

### 출력

| ToyPy | Python |
|---|---|
| `화면에 보여줘 "안녕"` | `print("안녕")` |

### 반복문

```
3번 반복해:
    화면에 보여줘 "또!"

0 부터 10 이전까지 하나씩 숫자를 늘려가며 i 이라고 부르고:    # range(0,10)
    화면에 보여줘 i

1 부터 5 까지 하나씩 숫자를 늘려가며 i 이라고 부르고:         # range(1,6) — 포함
    화면에 보여줘 i

목록 에 있는 것들 하나씩 꺼내서 x 이라고 부르고:
    화면에 보여줘 x

영원히 반복해:
    ...
    멈춰          # break
    다음으로 넘어가  # continue

x > 0 동안 반복해:
    x 는 x - 1
```

### 함수

```

```

## 게임 만들기 기능

### 화면 제어
```
화면 깨끗이                      # cls / clear
(10, 5) 위치에 써줘 "X"          # 커서를 (x=10, y=5)로 이동 후 출력
```

### 더블 버퍼링 (깜빡임 없는 화면)

화면을 지웠다 다시 그리면 깜빡임이 심한데, 프레임 버퍼를 쓰면 부드럽게 렌더됩니다.

```
부드럽게 그릴 준비해             # 초기화 (한 번만)

영원히 반복해:
    프레임 시작                  # 버퍼 비우기
    프레임에 보여줘 "━━━━━"
    프레임에 이어서 보여줘 "●"
    프레임 줄 바꿔
    프레임 그려줘                # 한 번에 출력
    초당 30프레임 유지
```

### 키보드 입력
```
만약에 말이야 키가 눌렸어?:        # msvcrt.kbhit()
    키 는 눌린 키가 뭐야?           # 'up' 'down' 'left' 'right' 또는 문자
    만약에 말이야 키 == "up":
        ...
```

### 시간 제어
```
500 밀리초 기다려                 # time.sleep(0.5)
초당 60프레임 유지                # 프레임 레이트 고정
```

## 똑똑한 자동 기능

ToyPy는 단순 번역 이상의 편의를 제공합니다:

- **Auto-import**: `밀리초 기다려`, `무작위`, `키가 눌렸어?` 등을 사용하면 `time`, `random`, `msvcrt`가 자동으로 import됩니다.
- **Auto-helper**: `눌린 키가 뭐야?`, `초당 N프레임 유지`를 쓰면 필요한 도우미 함수가 자동 주입됩니다.
- **콜론 힌트**: 블록 키워드(`만약에 말이야`, `반복해` 등)에 `:`가 빠지면 경고해줍니다.
- **미변환 경고**: DSL로 인식하지 못한 줄(오타 등)을 줄 번호와 함께 알려줍니다.
- **인코딩 폴백**: UTF-8 우선, 실패 시 CP949로 재시도.
- **표현식 AST 파싱**: 연산자 우선순위와 중첩을 정확히 처리해 `a + b 를 숫자로 봐줘` 같은 조합도 올바르게 변환. 파싱 실패 시 원문을 안전하게 유지합니다.
- **f-string 지원**: `f"점수: {점수}"`처럼 Python f-string을 그대로 쓸 수 있습니다.

## 자주 묻는 질문

**Q. 변환된 코드에 이상한 한글이 보여요**
A. `⚠️ 변환되지 않은 의심 라인` 경고를 확인하세요. 키워드 오타(예: `화면에 보여줘` → `화면에보여줘`)가 있으면 그대로 출력됩니다.

**Q. `:`를 빼먹으면?**
A. 실행기가 `💡 문법 힌트`로 알려줍니다.

**Q. Windows가 아니면?**
A. 출력·논리·함수·클래스 등 대부분은 동작하지만 `msvcrt`(키 입력)와 콘솔 VT 모드는 Windows 전용입니다.

**Q. 한글 변수 이름을 써도 되나요?**
A. 네! `이름`, `점수`, `목록` 모두 그대로 Python 변수로 변환됩니다.

**Q. 변수 이름 끝에 `부터`·`까지`·`무작위`가 붙으면 어떻게 되나요?**
A. 파서가 자동으로 분리하니 안심하세요. `1부터 너비까지 무작위` → `random.randint(1, 너비)`로 올바르게 나옵니다.
다만 **변수 이름 자체를 `끝까지`, `까지` 같이 키워드와 동일**하게 짓는 것은 피해주세요(충돌).

**Q. 복잡한 한줄 표현식이 이상하게 변환돼요**
A. `a + b 를 숫자로 봐줘`처럼 중첩·결합이 있는 식도 AST 파서가 우선순위대로 처리합니다 (→ `a + int(b)`).
그래도 의심스러우면 괄호로 의도를 명확히 하세요: `(a + b) 를 숫자로 봐줘`.
