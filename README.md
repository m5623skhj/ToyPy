# ToyPy

한글 기반 DSL(Domain Specific Language)을 Python 코드로 변환하는 간단한
트랜스파일러입니다.

------------------------------------------------------------------------

## 📁 프로젝트 구조

    ToyPy/
     ├── Toypy.py
     ├── TranslatorRunner.bat   # 실행 파일
     ├── Code/                  # DSL 코드 작성
     └── PythonScript/          # 변환된 Python 코드 출력

------------------------------------------------------------------------

## 🚀 사용 방법

### 1. DSL 코드 작성

`Code/` 폴더에 `.dsl` 파일 생성

예:

    나 는 10

    만약에 말이야 나 > 5:
        화면에 보여줘 "크다"

------------------------------------------------------------------------

### 2. 실행

    TranslatorRunner.bat 

또는

    python Toypy.py

또는 특정 파일:

    python Toypy.py Test.dsl

------------------------------------------------------------------------

## 📘 문법 정리

### 🔹 출력

    화면에 보여줘 "텍스트"
    → print("텍스트")

------------------------------------------------------------------------

### 🔹 변수

    나 는 10
    값 은 20
    → 나 = 10
    → 값 = 20

------------------------------------------------------------------------

### 🔹 조건문

    만약에 말이야 조건:
    아니면 조건:
    전부 아니면:

------------------------------------------------------------------------

### 🔹 반복문

    3 번 반복해:
    → for _ in range(3):

------------------------------------------------------------------------

### 🔹 함수

    이런 기능이 있어 더하기(a, b):
        결과는 a + b

------------------------------------------------------------------------

### 🔹 입력

    값 은 값을 입력할래
    → 값 = input()

------------------------------------------------------------------------

### 🔹 논리 연산

    그리고 → and
    또는 → or
    아님 → not

------------------------------------------------------------------------

### 🔹 Boolean

    진짜야 → True
    가짜야 → False

------------------------------------------------------------------------

### 🔹 비교 연산

    ==, !=, >, <, >=, <= 그대로 사용

------------------------------------------------------------------------

### ✅ 주석

#### 단일행

    이건 상관 없는 이야기인데 설명
    → # 설명

#### 다중행

    여기서 부터
    여러 줄 설명
    여기까지는 상관 없는 이야기인데

------------------------------------------------------------------------

### ✅ 에러 디버깅 지원

-   변환 실패 라인 감지
-   ':' 누락 힌트 제공

------------------------------------------------------------------------

## 🧠 개념

ToyPy는 다음 구조를 가집니다:

    DSL (한글)
     → Toypy (변환기)
     → Python 코드
